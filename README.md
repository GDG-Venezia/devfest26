# DevFest Venezia 2026

Website for DevFest Venezia 2026.

The theme lives in [GDG-Venezia/devfest-hugo-theme](https://github.com/GDG-Venezia/devfest-hugo-theme)
and is included as a git submodule in `themes/devfest-hugo-theme`.

```bash
git clone --recurse-submodules https://github.com/GDG-Venezia/devfest26.git
hugo server
```

Update the theme to its latest version with:

```bash
git submodule update --remote themes/devfest-hugo-theme
```

The theme README documents every data file and the steps to start a new edition.
