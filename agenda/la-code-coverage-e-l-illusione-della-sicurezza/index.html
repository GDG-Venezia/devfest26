La Code Coverage e l'illusione della sicurezza

Schedule to be announced

Siamo sicuri che raggiungere il 100% di Code Coverage possa assicurarti di non avere bug nel progetto? Certo che no!

Se il tuo team punta a raggiungere il 100% di Code Coverage tramite unit test solo per vedere quel bel numero, questa sessione fa per te!

In questa sessione vedremo:

  • cos’è la Code Coverage, e quali benefici porta avere una buona percentuale di Coverage;
  • come generare report di Code Coverage in Visual Studio (con esempi in C#);
  • perché NON dovresti puntare ciecamente al 100% di Code Coverage;
  • com’è possibile avere il 100% di Code Coverage ed avere comunque un software inaffidabile; -come creare test che portino effettivo vantaggio;
  • Testing Pyramid vs Testing Diamond;
  • come creare Integration Tests con NUnit;

I partecipanti impareranno, tramite esempi pratici, perché il solo fatto di raggiungere il 100% di Code Coverage non rende automaticamente il loro sistema più affidabile.

E che, come si dice, “quality over quantity”!

Speaker
Davide Bellone Principal Backend developer | Microsoft MVP | Blogger
